# Changelog

All notable public changes are documented here. The project uses semantic versioning for package
interfaces; data snapshots and evidence cards also retain their own hashes and dates.

## [Unreleased]

### Added

- A package-bundled, zero-data catalog of 15 evidence-bounded case studies across eight capability
  lenses, with CLI list, show, audit, and export commands.
- A responsive static Evidence Studio with search and capability, result, and weapon filters.
- A French department spatial-access analysis over official licence, club, population, and facility
  records, including deterministic department-bootstrap intervals and explicit temporal limits.
- Repository and demo synchronization checks, CI for Python 3.11 and 3.12, wheel package-data smoke
  tests, GitHub Pages publication workflow, and dependency updates.
- SHA-256 binding for all 23 case-evidence files, a deterministic catalog synchronizer, and a
  regression gate that rejects machine-specific home paths in public evidence.
- A lightweight console dispatcher so zero-data showcase commands do not import the full source
  adapter graph.
- Source-distribution exclusions for raw, processed, cached, model, artifact, and row-level index
  payloads, plus an archive safety, required-content, and 5 MiB size gate; the repository evidence
  remains intact while package-manager downloads stay bounded.
- Package-wide coverage measurement with a 55% non-regression floor; the current heterogeneous
  adapter surface measures 56% without excluding low-coverage source modules from the denominator.
- Architecture, reproducibility, contribution, security, conduct, citation, and issue templates.

### Preserved

- All prior positive, negative, mixed, diagnostic, and regional-replication evidence. No valid
  quantitative result was removed to simplify the story.

### External follow-up

- Independent domain review and user studies, when external collaborators become available.
- Hosted evidence studio after GitHub Pages is enabled for the repository.

## 0.1.0 - 2026-08-16

- Initial public release with source adapters, data registries, three-weapon analyses, aggregate
  model cards, tests, and evidence-bound claim policy.
