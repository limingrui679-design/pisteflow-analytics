# Data atlas

Snapshot: **2026-08-16**. PisteFlow reports each source in its native unit. Bouts, clips, frames,
rankings, athlete-event rows, participants, and measurement cells are deliberately **not summed**
into one marketing total.

## Searched but not counted

The machine-readable exclusion registry is
[`data/registry/source-exclusions.yml`](../data/registry/source-exclusions.yml). It records, among
others:

- FD-7 and VirtualFencer paper counts without a public data release;
- two Roboflow projects that require an account or key, including conflicting public image counts;
- target-distance studies whose athlete- or trial-level raw data are not deposited;
- the empty, future-tense Longsword-Spatial-Physics-100 repository;
- UCF50 pending member-hash proof that it adds clips beyond UCF101;
- generic swordplay retained only as adjacent-domain format checks;
- misleading search matches such as the ASL dataset whose repository name is `epee`.

This negative registry is part of the result: “found on a page” is not equivalent to “acquired,
licensed, and usable.”
