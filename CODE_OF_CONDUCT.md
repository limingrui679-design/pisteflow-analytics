# Code of conduct

PisteFlow contributors are expected to make technical disagreement safe, specific, and evidence-led.

## Expected behavior

- Be respectful across differences in experience, identity, language, and domain knowledge.
- Critique claims, methods, and code without attacking people.
- Treat athlete privacy, research participants, and uncertain data labels with care.
- Disclose conflicts, correct errors openly, and credit sources and contributors.
- Accept that a negative result or rejected data source can be a successful contribution.

## Unacceptable behavior

Harassment, discriminatory language, threats, doxxing, sexualized attention, deliberate exposure of
private data, license evasion, and sustained bad-faith disruption are not accepted in project spaces.

Maintainers may edit or remove contributions, restrict participation, or report serious conduct to
the relevant platform. Enforcement decisions should be proportionate and should avoid publishing
additional private information.
